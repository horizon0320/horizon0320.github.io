[(pdf)]({{ '/files/3830454.3846643.pdf' | relative_url }}) [(code)](https://github.com/yanyuanOO/Code-SeC)

Existing security audits for Code LLMs mainly inspect final outputs. A model may memorize a secret without revealing it in its output, so output-based audits can miss this form of memorization and underestimate the associated leakage risk.

We propose Code-SeC, a decoding-time probing and intervention framework that analyzes candidate-token distributions and introduces a Trace-Uncertainty Score to detect memorization-related signals. We further use contrastive decoding to amplify these signals in the candidate-token space, enabling the detection of latent leakage risks before model release.
