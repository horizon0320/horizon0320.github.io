## Selected Publication

**Yanyuan Chen\*, Ruize Hui\*, Chen Hou, and Meikang Qiu.**

[*Code-SeC: A Decoding-time Probing Method for Characterizing Secret Memorization in Code LLM*](https://dl.acm.org/doi/10.1145/3830454.3846643). **Accepted at ACM CCS 2026.** Co-first authors.

Existing security audits for Code LLMs mainly inspect final outputs. A model may memorize a secret without revealing it in its output, so output-based audits can miss this form of memorization and underestimate the associated leakage risk. We propose Code-SeC, a decoding-time probing and intervention framework that analyzes candidate-token distributions and introduces a Trace-Uncertainty Score to detect memorization-related signals. We further use contrastive decoding to amplify these signals in the candidate-token space, enabling the detection of latent leakage risks before model release.

\* Equal contribution.
